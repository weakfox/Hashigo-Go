**梯子旗（Hashigo-Go、Tizi7）**:一种快速的单列棋盘的类围棋游戏。

**游戏规则**
- 棋盘：10格竖排，白棋先手，轮流落子
- 落子：仅空白格可下，禁止自杀落子
- 吃子：棋子无气立即被提，吃子为合法落子
- 结束：棋盘满、无合法落子、局面重复
- 胜负：存活棋子多者胜，数量相同为平局

具体规则细节请参考rule.md 

**作为游戏成立需要补足的设计**
- 开局随机落子。作为电脑游戏时以随机数完成；作为桌面游戏时需要导入另外的道具，如骰子或纸牌，以满足随机数生成的需求。
- 一单进入循环则立刻判负。否则游戏会永久进行。
- 边缘是否参与提子，需提前双方告知并了解。
- 可适当加长或缩短棋盘，因为只有一个维度。
